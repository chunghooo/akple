# 악플 수집기 (YouTube)

유튜브 주소를 넣으면 댓글을 전부 모아 악플을 골라내고, 고소장에 첨부할 수 있는 채증 자료로 정리하는 웹앱.

흐름: 주소 입력 → 댓글 수집(YouTube Data API) → 악플 분류(키워드 또는 AI) → 사람이 검토·선택 → Word 보고서 / Excel / 원본 JSON 다운로드

## 파일 구성
- `app.py` — 웹 화면과 유튜브 댓글 수집
- `classifier.py` — 악플 분류 (키워드 규칙 / Claude API)
- `evidence.py` — 채증 보고서(Word)·Excel 생성

## 1. YouTube API 키 발급 (무료, 5분)
1. https://console.cloud.google.com 접속 → 새 프로젝트 만들기
2. "API 및 서비스 → 라이브러리"에서 **YouTube Data API v3** 검색 → 사용
3. "사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키"
4. 하루 10,000 유닛 무료. 댓글 100개당 1유닛이라 영상 수십 개는 넉넉함

AI 분류를 쓰려면 https://console.anthropic.com 에서 API 키를 따로 발급 (유료, 댓글 1,000개에 몇백 원 수준).

## 2. 내 컴퓨터에서 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
브라우저가 열리면 사이드바에 API 키를 넣고 주소를 붙여넣으면 끝.

키를 매번 입력하기 싫으면 `.streamlit/secrets.toml` 파일을 만들어 저장:
```toml
YOUTUBE_API_KEY = "AIza..."
ANTHROPIC_API_KEY = "sk-ant-..."
```
(이 파일은 절대 깃허브에 올리지 말 것)

## 3. 발표용으로 인터넷에 올리기 (무료)
1. 이 폴더를 깃허브 저장소에 올림
2. https://share.streamlit.io 에서 깃허브 로그인 → 저장소 선택 → `app.py` 지정 → Deploy
3. 앱 설정의 Secrets 칸에 위 secrets.toml 내용을 붙여넣기
4. `https://내앱이름.streamlit.app` 주소가 생김 → 휴대폰에서도 접속 가능

## 채증 보고서에 들어가는 것
- 수집 개요: 영상 주소·제목·채널, 수집 일시(KST), 수집 방법, 피해자·수집자
- 유형별 건수, 반복 작성자
- 댓글별 상세: 작성자 닉네임·채널 주소, 작성 일시(수정 여부), 원문, 유형·심각도, 판단 근거, **댓글 바로가기 링크**, 댓글 ID
- 원본 JSON의 SHA-256 해시값 (수집 후 위·변조되지 않았다는 근거)

## 알아둘 점
- 키워드 방식은 빠르지만 비꼬기·돌려까기를 놓치고, 문맥상 무해한 말을 잡기도 함 → 화면에서 사람이 꼭 검토
- 모욕죄는 **피해자가 특정**되고(누구 얘기인지 알 수 있어야 함) 여러 사람이 볼 수 있는 곳에 쓰인 경우 성립. 영상 속 인물과 고소인이 같은 사람이라는 점을 고소장에 함께 적어야 함
- 유튜브 닉네임만으로 작성자 실명은 알 수 없음. 수사기관이 구글에 정보를 요청하는 단계가 따로 있음
- 댓글은 언제든 삭제될 수 있으니, 수집 직후 원문 링크 화면 캡처도 같이 남겨둘 것
- 수집 데이터에는 남의 닉네임·채널 정보가 들어있으니 고소 목적 외로 공유하지 말 것
